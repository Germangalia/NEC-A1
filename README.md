## Install instructions
### 1. Create the virtual environment

#### On Windows (PowerShell or CMD)

```bash
python -m venv venv
```

#### On macOS / Linux

```bash
python3 -m venv venv
```

---

### 2. Activate the virtual environment

#### On Windows (PowerShell)

```bash
.\venv\Scripts\Activate
```

On Classic CMD:

```bash
venv\Scripts\activate
```

#### On macOS / Linux (bash/zsh)

```bash
source venv/bin/activate
```

---

### 3. Install dependencies with `pip`

With the virtual environment activated:

```bash
pip install -r requirements.txt
```

(If you use macOS/Linux and your system has Python 3 as `python3`, you may need to use `pip3`, but within the environment `pip` is usually enough.)

---

### 4. Run your Python script

With the virtual environment activated and packages installed:

```bash
python partX_XXXXXXX.py
```

Replace `partX_XXXXXXX.py` with the name of the file.

---

### 5. Deactivate the virtual environment (when finished)

```bash
deactivate
```
